# Homepage Research Notes (Feb 9, 2026)

## Competitor pattern snapshot
Reviewed public messaging on:
- https://novoresume.com
- https://enhancv.com
- https://resume.io

Observed repeated pattern:
- Similar title framing: "Free Resume Builder / Resume Maker".
- Similar value framing: "create professional resume", "get interviews", "in minutes".
- Similar homepage architecture: hero + social proof logos/reviews + template gallery + feature stack + final CTA.

Implication for Resumeable:
- Competing on generic promise language alone makes brand memory weak.
- Distinction should come from a clear POV and concrete transformation proof above the fold.

## UX and interaction evidence
1. People scan web pages quickly, so headings and structure must be scannable.
- Source: https://www.nngroup.com/articles/how-users-read-on-the-web/

2. Above-the-fold still gets the strongest attention distribution.
- Source: https://www.nngroup.com/articles/scrolling-and-attention/

3. Trust is improved by clear, specific, non-hyped messaging and transparent claims.
- Source: https://www.nngroup.com/articles/trustworthy-design/

4. High-quality motion should favor transform/opacity for smooth performance.
- Source: https://web.dev/articles/animations-guide

5. Motion should respect accessibility settings (`prefers-reduced-motion`).
- Source: https://web.dev/articles/prefers-reduced-motion

## Decisions applied in implementation
- Switched from generic "AI vibe" gradients/orbs to an editorial layout with a restrained palette and distinct typography.
- Replaced generic hero promise with a sharper anti-generic positioning statement.
- Added a visible before/after transformation panel in the hero to prove value immediately.
- Kept one primary CTA path with secondary exploratory CTA.
- Added subtle but meaningful motion with reduced-motion fallback.
